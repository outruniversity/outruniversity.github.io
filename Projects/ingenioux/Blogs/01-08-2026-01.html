Is MTech CSE still worth it?

01 Aug 2026 · Alekha Chandra Sahoo
Abstract

The top-of-page gap under the back button was too tall, and the full-width write-up section below the intro didn't line up with it on desktop — it was capped at a narrower width than the image-and-text block above, so the two sections had different left/right margins even though nothing about the content itself changed. Mobile view was never affected since both sections already collapse to the same full-width, small-padding layout there.

Two changes fixed it: the eyebrow now sits roughly 60px closer to the back button instead of 150px, and this section's max-width now matches the intro grid's 1400px instead of the old 820px — so its left and right edges line up with the image and abstract text above it on any desktop width, with the same 64px side padding both sections always shared.
