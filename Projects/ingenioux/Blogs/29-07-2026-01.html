Starting the lab notebook

31 Jul 2026 · Alekh Chandra Sahoo
IMAGE

Why this log exists, and — since it's the first entry — a quick note on how it publishes itself. The Research section of this site is for finished thinking; this log is the opposite: small experiments, half-working ideas, dead ends, the kind of note that's useful for a day and forgotten by the next.

Why keep a log at all

Each entry is dated, short, and specific. No pressure to make it a proper essay — if something's just a couple of lines of "tried X, it didn't work, here's why," that's a complete entry. It exists so that work doesn't only show up here once it's polished.

How this page gets on the site

This is a plain HTML file living in the Blogs/ folder, named with the convention DD-MM-YYYY-01.html (a second post on the same day would be DD-MM-YYYY-02.html, and so on). Any image for the post goes in the Images/ folder. The three meta tags at the top of the file are what make it show up automatically on the main page:

<meta name="post-date" content="31 Jul 2026"> <meta name="post-title" content="Starting the lab notebook"> <meta name="post-excerpt" content="Why this log exists...">
The rule: index.html and script.js never list posts by name. index.html loads Blogs/manifest.js with a plain script tag, which is generated from these meta tags — so the only file you ever author by hand is the post itself.

Publishing a new entry

  1. Copy this fileas a template and rename it to today's date, e.g. 03-08-2026-01.html.
  2. Edit the meta tags and the top/intro/body sectionsat the top, and write the entry in the body below them.
  3. Run the generator— node generate-manifest.js — which rescans Blogs/ and rewrites manifest.json for you.
  4. Push itif this repo is on GitHub Pages, the included Action runs step 3 automatically on every push, so this step alone is enough.

That's it for the first entry. Future ones will be shorter than this — this one's doing double duty as documentation.
